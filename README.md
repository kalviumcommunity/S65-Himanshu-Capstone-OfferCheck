# Offer Check

Search a company before you accept an internship or job offer. Students report fake offers so the next student does not get scammed.

## Idea Brief

Fake internship and job offers target college students: an unknown company, a Gmail or look-alike email domain, and a demand for a "registration fee" before joining. Offer Check is a web app where students search a company or email domain, read reports from other students, and add their own report with evidence.

## Tech Stack

- Backend: Node.js, Express, MongoDB (Mongoose)
- Frontend: React (Vite) in `client/`
- Design: Figma
- Tracking: GitHub Projects
